# Content Package Schemas

`iwig-content-package-v2.schema.json` defines the stable contract for all completed, partial, and failed content packages. Consumers must tolerate additive fields and use `status`, `errors`, `limitations`, and `completeness` instead of guessing from missing files.

`iwig-analysis-index-v1.schema.json` defines the no-network, analysis-ready projection generated by IWIG.
