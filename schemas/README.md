# Content Package Schemas

`content-package-v1.schema.json` defines the stable minimum contract for all completed, partial, and failed content packages. Consumers must tolerate additive fields and use `status`, `errors`, `limitations`, and `completeness` instead of guessing from missing files.

`analysis-index-v1.schema.json` defines the no-network, analysis-ready projection generated by `xhs-content-package-indexer`.
